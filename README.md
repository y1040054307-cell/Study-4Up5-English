# 向阳英语成长岛

面向福建小学三至六年级学生的长期英语自学网站。课程按闽教版主题组织，讲解、例句、对话、阅读与练习均为原创学习材料，不复制教材课文。

## 主要功能

- 三至六年级、上下册共 8 册课程库
- 52 个主题单元，每单元 6 个学习步骤
- 必备单词、拓展单词、重点句型与规则解释
- 单词本中每个重要单词提供3个不同例句，并解释整句意思和单词在句中的作用；学完本单元全部单词后进入20题独立填词测试
- 每张单词卡增加词汇档案：词性、名词单复数或动词词形、本课词义与常见义，并标出“人工复核”或“规则推断·待复核”
- 每单元扩充为8个核心与迁移句式、3组共18句情境对话、3篇分级原创阅读、15个读后问题和20题分层练习
- 新增三至六年级学习总纲与知识思维导图，可按年级、册别、单元快速跳转，并集中查看学习目标、必备词和重点句型
- 新增英语启蒙学习园地：26个大小写字母认识表、字母名称与常见发音、自然拼读起步路线，并将48音标课堂统一收纳到同一大模块
- 每日 20—30 分钟任务，包含“看中文写英文”和“看英文写中文”的自动判分默写
- 48 个基础音标、发音口型提示、标准示范音与最小对立词辨音
- 单词、例句、课文和音标采用国内自然语音优先的多级播放方案，并支持自然人声离线包
- 小学必备、高考核心和“我的学习词库”三类可搜索点读词典
- 重点句型支持逐词点读和中文释义
- 连续学习记录与成长日报
- 签到和任务奖励小太阳，用于照顾电子植物
- 每日历史巩固只从已经学习过的单元抽取单词，并按1、3、7、15、30天间隔优先安排到期词，不提前出现未来内容
- 10种分级植物商城；学习不会自动喂养，有多少小太阳就能手动浇灌多少次
- 植物拥有阶段升级进度条、6个花园种植位和按品质分组的原创植物图鉴
- 原创塔防风学习植物只借鉴“植物守护花园”的通用玩法思路，不使用其他游戏的角色名称、造型或素材
- 动物精简为小猫、小狗、小乌龟3种，每种都有4个从幼崽到完全成长的原创手绘形态
- 已领养动物会在学习首页以动态浮窗陪伴，支持摸摸、跳跃、散步和喂食
- 动物由网页身体部件绘制，拥有呼吸、眨眼、摇尾巴等持续动作，并非单张图片
- 学习记录保存在当前浏览器，无需注册账号；支持5个身份统一导出/导入JSON备份，导入与设置修改受4位家长码保护
- 5个可切换的独立学习档案：小宇航员、智慧船长、闪电博士、阿洛探险家、米娅小博士；课程、错词、奖励、植物和动物数据互不混用
- 系统语法课堂包含冠词和限定词、名词、动词、介词与固定搭配、代词、形容词与副词、句子结构、从句与连接词8个主题；每个主题都有规则、对比例句、至少8题原因讲解和80%通过检查
- 支持免下载添加到手机或平板主屏幕，使用原创应用图标并以独立网页应用形式快速打开
- 新增英语学习能力中心：30题分组入学诊断、6关48题自然拼读、每单元单词与句子听力、15项口语录音回放；训练进度按5个学习身份分别保存
- 重构单元测评中心：每单元1份50题福建公开卷常见题型参考卷；六年级每单元另有1份60题小升初强化卷。所有题目为原创组卷，提交后提供逐题词义、正确原因与错因
- 重构六年级“小升初强化资料课”：入口只显示在六年级课程中；12周共60节资料课，每课包含知识讲解、3个例句、3道随堂检查和订正完成流程
- V36 修复大文件发布不完整导致的网页无法启动问题，并强制更新网页与离线缓存

## 教材说明

新版教材正在分年级启用，各地区、学校的实际启用进度可能不同。网站用闽教版单元主题帮助孩子理解和练习，但不能替代学校正式教材。使用前请对照孩子实际课本的单元名称。

v38 起，每一册课程都显示独立的教材版本和同步状态：三年级上册标为“2024修订版·目录已核对”；其余册次根据现有核对程度分别标为“主题已对照”“部分对照”“待纸书复核”或“非新版同步”。课程选择页、学习总纲、单元卡片、单元学习页和试卷页均可看到相应说明。所有讲解、例句、阅读和练习均为本站原创，不是出版社教材原文或官方电子课件。

v39 完成全站审核优化：正式测评改为每单元50题足量综合卷，六年级另配60题衔接卷；所有关键学习模块采用80%或有效互动完成门槛；加入间隔复习日程、家长码与数据备份、手机“核心5项+更多”导航、无障碍焦点和减少动画选项，并将教材同步措辞按每册实际核对状态动态显示。

v40 继续保持闽教版课程体系，并将“目录已核对”的三年级上册建设为首册精品示范册：四个单元的3组情境对话、3篇分级阅读和20题单元练习均逐单元人工编写；所有单元新增“深度学习地图”，补充词汇分类、句型逻辑、易错词形、语序检查和真实迁移任务。

v41 为课程内“必备单词”和“重点句型”加入本机录音跟读：每个必备词至少录音2次，每个必备词下的3个例句各录音1次，每个重点句型至少录音3次；录音次数和原有80%测试门槛同时达标后才能完成任务，录音不上传服务器。

v42 在全部学习模块共用的页面底部加入家庭学习使用声明，并同步更新网页、离线缓存和主屏应用版本。

## 语音说明

v26 起，课程离线包不再使用 eSpeak 机械合成音。单词和词典词条优先采用有道词典自然英语语音，句子、对话和故事优先采用百度翻译自然英语语音；在线自然语音失败时再使用设备英语语音。48 个音标示范音参照并注明来源于[新东方48音标卡](https://www.xdf.cn/zhuanti/bd-phonetic-alphabet-card/index.html)。

离线包由 GitHub Actions 运行 `tools/build-natural-audio.mjs` 分包生成，方便手机和平板在国内网络下下载。网站只接受带 `codec: "mp3"` 标识的自然语音包作为离线播放源，旧机械语音包会被忽略。

v29 修复了线上播放器与 MP3 分包索引不兼容的问题。联网点读会直接按需读取同源自然人声片段；用户主动下载后，全部课程与音标语音可离线播放。

v30 新增“英语学习能力中心”。孩子可先完成入学诊断获得建议起点，再按自然拼读、单元听力和口语录音路线训练；口语必须完成一次录音回放后才能领取奖励。

v31 将能力中心升级为足量训练：入学诊断扩展为30题并分3组完成；自然拼读6关各8题、合计48题；每个课程单元自动提供约13道单词与句子听力题，以及15项从单词到整句的录音回放任务。

v32 新增“单元考卷中心”。每份试卷按听力辨义、词汇基础、句型运用和综合理解四部分组织，答完30题后统一交卷、查看逐题解析并保存个人最高分；累计卷严格按课程顺序取历史单元，不提前出现未来内容。

v33 扩充四个单元学习模块的实际学习量，新增全课程学习总纲与单元知识地图，并建立从字母认识、字母声音、自然拼读到48音标的英语启蒙完整入口。

v34 升级“单元提高卷”的近形词、近音词、相似词义与词形辨析；交卷后为题干和全部选项逐词补充中文释义，并分别解释正确与错误原因。

同时重新整理顶部主导航顺序，将学习内容与练习入口放在前方，并将“成长报告”统一命名为“成长日报”。

## 使用

直接打开 GitHub Pages 网站即可。建议先在“课程”中选择孩子当前年级、学期和单元，再从首页点击“继续学习”。

> 测试资源模式已经关闭。每个学习身份从0开始，通过签到、课程和练习获得自己的小太阳与粮食。
