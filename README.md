# 向阳英语成长岛

面向福建小学三至六年级学生的长期英语自学网站。课程按闽教版主题组织，讲解、例句、对话、阅读与练习均为原创学习材料，不复制教材课文。

## 主要功能

- 三至六年级、上下册共 8 册课程库
- 52 个主题单元，每单元 6 个学习步骤
- 必备单词、拓展单词、重点句型与规则解释
- 原创情境对话、原创阅读、分层小测与错词复习
- 每日 20—30 分钟任务，包含“看中文写英文”和“看英文写中文”的自动判分默写
- 44 个基础音标、发音口型提示、跟读示范与最小对立词辨音
- 小学必备、高考核心和“我的学习词库”三类可搜索点读词典
- 重点句型支持逐词点读和中文释义
- 连续学习记录与成长报告
- 签到和任务奖励小太阳，用于照顾电子植物
- 学习记录保存在当前浏览器，无需注册账号

## 教材说明

新版教材正在分年级启用，各地区、学校的实际启用进度可能不同。网站用闽教版单元主题帮助孩子理解和练习，但不能替代学校正式教材。使用前请对照孩子实际课本的单元名称。

## 使用

直接打开 GitHub Pages 网站即可。建议先在“课程”中选择孩子当前年级、学期和单元，再从首页点击“继续学习”。
