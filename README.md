# 向阳英语成长岛

面向福建小学三至六年级学生的长期英语自学网站。课程按闽教版主题组织，讲解、例句、对话、阅读与练习均为原创学习材料，不复制教材课文。

## 主要功能

- 三至六年级、上下册共 8 册课程库
- 52 个主题单元，每单元 6 个学习步骤
- 必备单词、拓展单词、重点句型与规则解释
- 单词本中每个重要单词旁直接显示完整句式、中文理解和逐词点读；学完本单元全部单词后进入独立填词测试
- 原创情境对话、原创阅读、分层小测与错词复习
- 每日 20—30 分钟任务，包含“看中文写英文”和“看英文写中文”的自动判分默写
- 44 个基础音标、发音口型提示、跟读示范与最小对立词辨音
- 小学必备、高考核心和“我的学习词库”三类可搜索点读词典
- 重点句型支持逐词点读和中文释义
- 连续学习记录与成长报告
- 签到和任务奖励小太阳，用于照顾电子植物
- 每日历史巩固只从已经学习过的单元抽取单词，不提前出现未来内容
- 10种分级植物商城；学习不会自动喂养，有多少小太阳就能手动浇灌多少次
- 植物拥有阶段升级进度条、6个花园种植位和按品质分组的原创植物图鉴
- 原创塔防风学习植物只借鉴“植物守护花园”的通用玩法思路，不使用其他游戏的角色名称、造型或素材
- 动物精简为小猫、小狗、小乌龟3种，每种都有4个从幼崽到完全成长的原创手绘形态
- 已领养动物会在学习首页以动态浮窗陪伴，支持摸摸、跳跃、散步和喂食
- 动物由网页身体部件绘制，拥有呼吸、眨眼、摇尾巴等持续动作，并非单张图片
- 学习记录保存在当前浏览器，无需注册账号

## 教材说明

新版教材正在分年级启用，各地区、学校的实际启用进度可能不同。网站用闽教版单元主题帮助孩子理解和练习，但不能替代学校正式教材。使用前请对照孩子实际课本的单元名称。

## 使用

直接打开 GitHub Pages 网站即可。建议先在“课程”中选择孩子当前年级、学期和单元，再从首页点击“继续学习”。

> 当前临时开启测试资源模式：小太阳和粮食各显示 99999。测试资源不会写入正式资源记录，关闭测试模式后可恢复正式的从零获取规则。
