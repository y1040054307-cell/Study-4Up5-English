# 向阳英语岛

面向福建小学四年级升五年级学生的 **2026 闽教版英语暑假15天自学工具**。

## 主要功能

- 前7天复习闽教版四年级下册，后8天预习五年级上册
- 单词卡、设备英文发音、生活化原创例句与五题闯关
- 每日签到、完成单词和闯关任务可获得“小太阳”
- 使用小太阳喂养电子植物，解锁种子、幼苗、花朵和大树阶段
- 中断学习后植物会降低活力并枯萎休眠，恢复学习后可以救活
- 学习记录仅保存在当前浏览器，不需要账号，不收集学生个人信息
- 支持手机、平板和电脑，可在首次加载后离线使用主要功能

## 教材范围

课程主题参照福建教育出版社《义务教育教科书·英语（三年级起点）》四年级下册、五年级上册的2026同步目录设计。网站中的中文解释、例句、练习和视觉素材为本项目重新编写或制作，不包含教材扫描页，也不重新分发出版社配套音频。

## 使用方式

直接打开发布后的 GitHub Pages 地址即可。点击“今日签到”，完成当天单词和闯关任务，领取小太阳并喂养植物。
